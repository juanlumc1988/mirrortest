Objects that the test compares or indexes need the operators it uses. `a == b`, `EXPECT_EQ(a, b)` and `EXPECT_TRUE(a == b)` are one `bool operator==(const Point& b) const`; `<`, `!=` and `>=` are theirs; comparisons are `const` and return `bool` whatever the test calls them through. `p[0]` read and compared with an `int` is `int operator[](int) const`; `grid[3] = 7` writes, so it returns `int&` and is not `const`. `EXPECT_EQ(sensor.position(), origin)` makes `position()` return a `Point`, and `Point` the comparison.
