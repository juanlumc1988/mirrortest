`Color::Red` is a value of a type that nothing declares and the test never builds or calls: an enum. `Color` becomes `enum class Color { Black, Red, Blue }` (enumerators once each, in the order the test first used them, each with a note saying where), in the header whose name matches, and `Mode`, which has none, in the first header the test includes. What `Paint` takes and returns is the enum, by value, and `paint.h` includes `color.h`. `Color c = Color::Blue;` and `paint.color() == c` do not make `Color` a class.
