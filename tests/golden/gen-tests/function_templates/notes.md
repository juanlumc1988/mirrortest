A function template is tested through the instantiations the configuration lists (`template_instantiations`), as a class template is: one test for each, in the file of the header's functions, named after the function and its arguments (`clamp_to_int`, `scaled_long_8`). The parameters are replaced in the types of the function, a parameter left out takes its default (`scaled<int>` is `scaled<int, 4>`), and the call names the arguments (`acme::clamp_to<int>(lo, hi, value)`) instead of leaving them to deduction, so that the instantiation that is tested is the one that was listed. `unlisted` is skipped with a warning that says which line to add; `count_all` is listed, but a parameter pack has no single argument, so it is skipped with a warning too. `plain` is not a template and is tested as before.
