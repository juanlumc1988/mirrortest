With `gtest.parameterised`, a method with arguments is a `TEST_P`: a struct of the arguments, a `TestWithParam` over it, the test reading one row into locals, and an instantiation with a single row of default values for the person writing the test to extend. What cannot be a column keeps its locals: an rvalue reference (it is moved from a local) and a `unique_ptr` (a row is copied). Methods without arguments, constructors and the destructor stay plain tests.
