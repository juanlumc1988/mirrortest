`gtest.mocks`: a mock header for every interface of the header. `MockSensor` declares each pure virtual function with its specifiers (`const`, `noexcept`, `ref(&)`, `override`) and puts a return type or an argument that has a comma in parentheses (`(std::map<int, std::string>)`), which is how gmock is told the comma is not the macro's. `MockProbe` is also given what `Probe` leaves pure from `Sensor` (everything but `read`, which `Probe` implements), its own function first. `Controller` is not an interface: no mock.
