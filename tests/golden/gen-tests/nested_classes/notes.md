A public class nested in a class is tested like any other, through the name that reaches it from the namespace: `Tree::Node sut;` in `TEST(Tree_NodeTest, …)`, in `tree_node_test.cpp`. The types of the classes around it are written through them (`Tree::Node`, `Tree::Cursor::Step`), a nested class that derives from a sibling asserts it by that name, and what has nothing to test (`Step`, data only) is silent. The protected `Hidden` has no test: a test cannot name it.
