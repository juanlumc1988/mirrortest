A class template is tested through the instantiations the configuration lists (`template_instantiations`): one file and one suite for each (`box_int_test.cpp`, `Box_intTest`; `box_std_string_8_test.cpp`), the arguments written as given and the defaulted parameter left to the template. The injected class name (`Box clone()`) is the instantiation, the nested type is named through it (`Box<int>::Item`). `Pair` is not listed: it is skipped with a warning that says how to list it.
