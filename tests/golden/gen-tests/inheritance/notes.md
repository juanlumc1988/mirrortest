A class that derives from others gets an `Inherits` case before the rest: one `static_assert(std::is_base_of<…>)` per direct base, whatever its access or virtual-ness, with the base as written (`Counted<int>`) and the class with its namespace in the message. What the class inherits is not repeated in its suite (the comment says so); a class with nothing public of its own (`Tag`) is planned for that case alone; a class without bases (`Plain`) has none.
